# The Old Well - example mod pack

Copy this folder into your AVAM&M `Mods` folder (see Settings > General > Data for where that is) and
enable it on the Mods screen. It adds a stair from Brindlemoor (east of the inn) down into a small
dungeon with a new monster, a charm to find and a journal entry.

Files: `pack.json` (required), `monsters.json`, `items.json`, `quests.json`, `Maps/oldwell.json`,
`mapPatches.json` (adds the stair to Brindlemoor) and `Graphics/Monsters/well_crab.png`.

The crab sprite is "fire crab" from the Dungeon Crawl Stone Soup tiles (CC0 1.0,
https://opengameart.org/content/dungeon-crawl-32x32-tiles). The pack's JSON is MIT like the game.
